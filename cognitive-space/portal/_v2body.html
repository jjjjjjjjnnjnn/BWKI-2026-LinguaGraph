Findings

Findings A–E

Five claims, each with its limit attached. Preliminary until stated otherwise.

A · Density peaks early

Curriculum graphs densify in middle school, then thin out (CDS 0.271 → 0.073, 3.7×).

Frozen snapshot: computed on the June-2026 dense pipeline (574-node generation, dense code path since lost). Kept frozen, never recomputed — see forensic notes.

B · Shallow hierarchies

Concept depth ≤ 8 (math ≤ 8); 83% of concepts are hierarchy roots.

Frozen snapshot, same provenance as A.

C · Language separates structure

Textbook LDS-K: zh-de 0.519 far below EN-involving ≈0.93 (0.933 / 0.938). The raw zh-de closeness was falsified as a label artifact (T1 decontamination 0.556 → 0.020).
Two-Tier control: what vectors (don't) show

Open-weight embeddings (nomic-embed-text-v1.5, 768 dims, 934 terms) compress all three pairs into 0.48–0.52 (spread 0.0445) and do not reproduce the textbook split (spread 0.419). Rank order only — never raw values. Vectors are the control baseline, never the evidence.

Tier-1: 0.519 / 0.933 / 0.938 Tier-2: 0.4804 / 0.5249 / 0.4888

D · Systems differ in coverage

Textbook–curriculum coverage varies widely — granularity (safest reading) and governance (hypothesis) both fit.

E · Humans can't separate it (between-subject)

N=15 falsifies ΔLDS > 0 between-subject (human LDS-C ≈ split-half floor); the LLM within-subject margin (+0.08–0.09) shows the signal exists. Earlier simulation comparison withdrawn.
Humanities falsification probe (one-way only)

An independent humanities slice can weaken the "curriculum-specific" claim but never confirm the math result. Pass: math splits, humanities doesn't → curriculum-specific. Alarm: both split → downgrade to "shared cross-domain". Current: pilot N=8 (0.704/0.727/0.751) placeholder — no pass/alarm call.

Method

Methodology in five steps

Extract → align → measure (LDS) → null-test (500 permutations) → replicate (59 models).

1 · Extract

68 textbook files → 741 concepts / 665 relations, temperature=0, multi-model audit.

2 · Align

219 trilingual groups; hard matching (lowercase, ß→ss, synonym map). Unmatched stays unmatched.

3 · Measure

LDS = 1 − mean(GED similarity, node/edge Jaccard). Frozen: 0.519 / 0.933 / 0.938.

4 · Null-test

500 label permutations; p<0.004 is the resolution limit (1/500), not tuning. ZH-DE 59/59 pass, margin floor 0.033.

5 · Replicate

Identical P1 protocol on 59 measurements (54 models): mostly DashScope + bare-hosts/Kilo/Cohere/NIM/Cloudflare/LM-Studio/opencode-go. Availability sample, not a preregistered matrix.

Provenance: HF model SHAs are today's HEADs, not experiment pins; served revision UNVERIFIED; local phi file is a community quant build (snapshot + App. W).

Limits

Limitations

Every limit, before the conclusions. No silent upgrades.

Chunking boundaries

Section-level chunks; cross-section references count as dangling. Bias is one-sided and conservative.

Hard-match penalty

Synonymous-but-differently-spelled pairs are penalized by construction; sensitivity is single-digit.

Sparse annotation

Human pilot N=8 is a shape placeholder; powered design is N=30. 219 aligned vs 359 unaligned groups.

temperature=0 is not deterministic

Ensemble intra self-agreement only 0.59–0.73 (≈27–41% run disagreement). Single-run values are snapshots with fluctuation bands.

Snapshot instability

Vote totals mix two threshold scales and must be shown split; inter means across refills are not comparable — no trend claims.

Small samples

92 gold labels suffice for overall F1, not for per-language per-domain splits. German math F1 (0.506) has high variance.
