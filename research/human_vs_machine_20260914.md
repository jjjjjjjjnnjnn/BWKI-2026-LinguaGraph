## 2. 解读（只许这样报）

1. **人类 pilot 与向量同为"均匀带"，与图谱的"结构化"形成对照**：N=8 pilot（0.70–0.75）
   与向量（0.48–0.52）都是窄带分布，教材 LDS-K 则 zh-de 显著更低。这一步只登记形态差异，
   不做因果归因（pilot 样本小＋社会话题与数学话题域不同，见 §4 证伪探针）。
2. **ΔLDS 方向（pilot − LDS-K）**：zh-de +0.232、zh-en −0.230、de-en −0.211——人类 pilot
   在 zh-de 高于教材基线、在涉英两对低于教材基线。该符号翻转是 pilot 级观察，
   正式检验待 N=30（`analyze_human_lds.py` 全管线：bootstrap CI＋Cohen's d＋Bonferroni）。
3. **机器≠人类**：向量层（预训练分布邻近度）既不等于教材结构，也不等于人类问卷行为；
   三源各测各的，任何"两源一致即互证"的说法都属违规外推——一致只许报"形态相似"，
   分歧只许报"测量本质不同"，不许报一方证伪另一方（证伪权只属于 §4 的人文探针设计）。

## 3. 人文子集"证伪探针"定位

- **是什么**：问卷中的人文/社会话题子集（pilot 已有社会话题数据，`analyze_human_between.py` /
  `analyze_sim_baseline.py` 为按话题分组 LDS 口径）独立于数学图谱，专职做**不对称证伪**。
- **逻辑（单向）**：
  - 若数学域 LDS 显著分化、而人文子集同语对 LDS 不分化（或符号反转）→ 支持"效应是
    数学课程结构特异的"，反对"通用语言距离"解释。探针**通过**。
  - 若人文子集复现同样分化 → 数学结论不被推翻，但"课程特异"主张被削弱，须降级为
    "跨域共有分化"，并追查通用因子。探针**报警**，不是定罪。
  - 人文子集**永远不能单独证实**数学结论（域不同，无传递性）。
- **执行**：N=30 到位后先跑全集 LDS-C，再跑人文子集切片（同一管线、同一 α、Bonferroni
  独立校正），两表并列登记，不得只报有利的一半。
- **当前状态**：pilot N=8 社会话题值（0.704/0.727/0.751）已 implant 为探针基线占位；
  正式探针结论等 N=30，今日不许提前报"探针通过/报警"。

## 4. 答辩话术卡（Q&A，一行一答）

| 评委问题 | 标准答（照读） |
|---|---|
| N=8 也敢报人类结论？ | 不敢。N=8 是管线 demo 占位，正式功效按 N=30 设计（86% power for ΔLDS>0，见管线注释）；今日人类列仅登记形态，不做显著断言。 |
| 向量和图谱哪个对？ | 不是对错关系，是两层测量：图谱测课程结构（主证据），向量测分布邻近度（对照基线）；向量均匀恰恰说明图谱的结构化不是通用语义噪声。 |
| zh-de 两列数值接近（0.48 vs 0.52）是否互证？ | 否。量纲不同（余弦距离 vs GED+Jaccard 合成），接近是巧合；只许比序结构，不许比数值。 |
| 人文探针若报警怎么办？ | 按 §3 单向逻辑降级"课程特异"主张为"跨域共有"，追查通用因子；不撤回数学 LDS 显著性（两检验对象不同，见蓝队 D5 分层辩护）。 |
| 500-perm p<0.004 是不是刷出来的？ | 是分辨率极限（500 置换下最小可报 p），59/59 全过且 margin 下限 0.033 为正；微观抽取噪声不改变宏观 margin 量级，见 `blue_defense_20260914.md §D5`。 |
| temperature=0 可复现吗？ | 判官调用 temperature=0、max_tokens=5（见 Tier-2 基线模型卡）；嵌入无采样随机性（同词同向量），重跑脚本即得同表，差异仅来自 LM Studio 模型版本更换（届时重登记版本号）。 |
