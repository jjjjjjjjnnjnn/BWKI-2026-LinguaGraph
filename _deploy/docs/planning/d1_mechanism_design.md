# LinguaGraph — D1 机制级实验设计：LLM-as-Subject 组内设计的语言分歧分解

> **生成**: 2026-08-08 | **状态**: 实验方案（待确认后执行）
> **依赖**: `docs/planning/research_directions_20260808.md`（方向选择）· `scripts/lds_c_extract.py` / `lds_c_compute.py`（复用）
> **背景**: 用户批准 D1 执行，但要求**深入机制层面**——不能只报"语言变了概念图"，而要回答"**为什么**同一 LLM 跨语言产生分歧"。

---

## 0. 科学定位：从"是否分歧"到"分歧从哪来"

D1 核心设计已解决**构造问题**（同模型 = 组内设计）。机制级设计进一步回答**机制问题**：同一权重集合，仅改提示词语言，为何输出概念图不同？

我们把"语言效应"分解为**五个候选机制**，每个机制对应一个可分离的探针。这是本研究的方法学贡献——把"LLM 语言偏置"这个黑箱拆成可检验的机制层。

---

## 1. 候选机制（为什么同一 LLM 会跨语言分歧）

| # | 机制 | 含义 | 测法 |
|---|------|------|------|
| **M1 表层词法** | 不同语言用不同词形，但底层概念相同 | 对齐后分歧应消失 | 词干+同义词对齐（`canonical_key`）——**已有证据：仅合并 5% → M1 被证伪** |
| **M2 语料联想统计** | 各语言训练语料的联想统计不同（如 ZH 语料"自由"更常接"法律/制度"） | 分歧 = 语料统计副产物，非认知 | 同模型三语自由联想（M2 探针）→ 若概念图分歧 ≈ 联想分歧，则机制是统计而非结构 |
| **M3 文化框架激活** | 语言编码触发了模型记忆中的文化分类框架（最有趣：Whorfian 意义上的"框架"） | 语言是"文化载体的开关" | 框架-代码解耦（M3 探针） |
| **M4 采样方差** | 温度采样随机性（非语言） | 必须作为噪声底 | 组内重采样 Split-Half（已内置） |
| **M5 产出-提示语不一致** | 问题语言 vs 回答语言不同 → 看哪个驱动 | 定位"指令条件化"层 | 答案语 vs 提示语解耦（M5 探针） |

**逻辑链**：M4 是噪声底（一切差异与之比）。M1 已证伪（对齐只合并 5%）。剩下的 M2/M3/M5 是真正的候选——本设计用三个探针把它们分离。

---

## 2. 探针设计（三组受控操纵）

### P1 — 组内核心（语言主效应）
> 同一模型，独立 API 调用（会话重置，无上下文累积——**用户强调的"真组内 vs 伪组内"**），3 语言 × 5 主题 × k 次重采样，直接概念提取。

- 输出：`LDS-C(语言对)` vs `组内 Split-Half(噪声底)` → 语言主效应是否 > 0
- 关键卫生要求：**每次调用全新 session（新请求，无历史）**；反平衡主题顺序；固定温度。

### P2 — 框架-代码解耦（M3 探针，**核心机制实验**）
> 语言代码与文化框架**正交化**：
> - 条件 A：ZH 提示 + "你是中文母语者，按中文文化框架思考"（自然）
> - 条件 B：**ZH 提示 + "你是德语母语者，按德语文化框架思考"**（代码 ZH，框架 DE）
> - 反向同样（DE 提示 + ZH 框架）
> 若条件 A vs B 产出差异显著 → **框架独立于代码驱动分歧** → 机制是"文化知识激活"而非"语言形式"。
> 若 A ≈ B（仅语言代码重要）→ 机制是"产出统计/词汇"层。

**这一探针把 Whorf 假设从"语言代码"精确到"语言作为文化框架载体"——是机制解释的核心证据。**

### P3 — 同模型自由联想（M2 探针）
> 同一模型，5 主题词 × 3 语言，生成自由联想（每主题 ~10 联想，k 次）。计算联想集合的语言间 LDS。
> 若 P1 的概念图分歧 ≈ P3 的联想分歧（同模型内）→ 概念图分歧是**联想统计**的副产物（语料统计机制）。
> 若 P1 ≫ P3 → 概念图分歧超出联想统计，存在**结构层**（框架/语义组织）。

### P5 — 答案语 vs 提示语解耦（M5 探针，可选）
> 条件：ZH 问题 + "用 DE 思考并回答" vs DE 问题 + "用 DE 思考"。比较谁驱动概念差异。

## 3. 数据矩阵与成本

**关键优化**：P2 的"自然条件"（ZH代码+ZH框架、DE代码+DE框架）与 P1 完全共享——每个"被试"= 5 次**per-topic 作答调用**（避免 deepseek 多item推理爆炸）+ 1 次整卷提取调用（失败回退 per-topic）。P2 只需新增 2 个交叉条件。

| 探针 | 条件 | 被试数 | 调用（作答+提取） | 机制 |
|------|------|:---:|:---:|------|
| P1 语言主效应 | ZH 自然 / DE 自然 / EN 自然 | 3×10=30 | 30×(5+1)=180 | 语言主效应 |
| P2 框架解耦 | 交叉：ZH码+DE框架 / DE码+ZH框架 | 2×10=20 | 20×(5+1)=120 | M3 |
| P3 自由联想 | 3 语言 × 5 主题 | 150 | 150（联想即输出，无提取） | M2 |
| P5 答案vs提示语 | 2 交叉（ZH问DE答 / DE问DE答） | 2×10=20 | 20×(5+1)=120 | M5 |
| **合计** | | | **~570 调用** | |
| 成本 | deepseek-v4-flash @ opencode GO | ~1M token | 约数美元 | |
| 时间 | ~10s/调用 | ~1.5–2h（后台） | 断点续跑 | |

**P2 判定逻辑**（这是核心机制证据）：
- LDS(自然ZH, 自然DE) = P1 语言主效应
- LDS(ZH码+ZH框架, ZH码+DE框架) = **同代码、异框架** → 若 > Split-Half(ZH) 底，则**框架独立驱动概念分歧**
- 若自然ZH vs 交叉ZH差异 ≈ 语言主效应 → 框架=语言分歧的全部；若 ≈ 0 → 分歧来自代码/词汇层

## 4. 分析管线（全部可复现）

1. **概念提取**：P1/P2 → 三语概念集（`lds_c_extract` 逻辑改造为 LLM-作答版）；P3 → 联想集
2. **对齐**：`canonical_key`（词干+同义词）→ 语言聚合概念集
3. **LDS-C + Bootstrap CI**：`lds_c_compute`（1000 次）
4. **噪声底**：组内 k 次采样 Split-Half（`within_language_split_half`）
5. **机制判定**：
   - 语言主效应 = LDS-C(P1) − Split-Half 底，Bootstrap 检验
   - 框架效应 = LDS-C(P2: 自然 vs 交叉框架)，配对比较
   - 统计机制 = 相关/回归：P1 概念图分歧 ~ P3 联想分歧（同语言对）
6. **主题级 + 6 类 Codebook**（`lds_c_thematic`）：ZH/DE/EN 方向性框架（法理/自主/具体）在 LLM 条件化下是否复现 → 与 N=15 人类方向性互证
7. **图结构指标**（v3）：节点/边 LDS，判断分歧在"选词"还是"组织"

**产出**：
- D1 结果表（语言主效应 + 机制判定）
- 机制层级图：表层词法(M1 已证伪) → 联想统计(M2) → 文化框架(M3) → 采样(M4)
- 与人类 N=15 方向性对照表

## 5. 诚实边界（论文方法学部分）

1. **模型 ≠ 人类认知**：LLM 的分歧机制不能直接外推人类，但作为**受控认知代理**回答"语言作为文化框架载体"是否影响概念组织，是有效的方法学实验。
2. **训练语料偏置**：M2 与 M3 的区分本身就是对"偏置来自训练语料而非语言本身"的检验——这是讨论点而非缺陷。
3. **deepseek 推理爆炸坑**：沿用"按主题小调用 + 空结果显式重试"对策；P3 联想任务若触发爆炸，降 BATCH。
4. **真组内 vs 伪组内**：全部独立 API 调用、会话重置、反平衡——在方法学部分显式声明（对标 Sclar 2023 顺序效应问题）。
5. **行为测量 vs 自我报告**（文献启示）：材料[87] (2025) 发现 LLM 的语言自报与行为表现存在显著脱节（仅 ~25% 显著关联）。**本项目不依赖自我报告**——LDS-C 测的是模型**输出的概念图**（行为产物），正因如此它回避了自我报告不可靠的问题，直接测量可观测行为。这是 D1 相对"人格测评 LLM"类研究的**方法学优势**，须在论文强调。

## 5.5 分析模型升级（文献启示：混合效应模型）

用户提供的综述指出：LLM 组内设计已从"简单重复测量"演进到"混合效应模型 + 因果验证 + 外部评估"。据此，D1 分析从 Bootstrap CI 升级为双轨：

1. **Bootstrap CI + Split-Half 底**（保持现有，直观）：LDS-C 语言对 vs 噪声底，确定性判定。
2. **线性混合效应模型 (LMM)**：以主题为被试单元、语言×框架为固定效应、采样为随机效应，对概念级指标（Jaccard 相似度、概念数、主题类别占比）建模。
   - `similarity ~ language_pair + frame + (1|topic) + (1|sample)` — 分离语言主效应与框架效应的**边际贡献**
   - 呼应材料[21] (2024) 的混合效应方法，方法学上更严谨
3. **外部评估**（呼应材料[66] 2024）：主题分类不用模型自述，用独立 LLM 分类调用（`lds_c_thematic.py` 6 类 Codebook）——与"自我报告不可靠"问题解耦。

**因果层**（材料[93] 2026 的方向，超出本项目范围，列为 Future Work）：冻结模型参数、操纵内部表征（如情感/框架神经元方向）验证"框架效应是否来自算法结构"。D1 只做相关+对照实验，因果验证留白。
