How to operate the graphs

ControlFunction
SearchFind any concept by name in three languages; Enter flies the camera to it.
Universe / Space-Fill / CompareUniverse = free force layout (click resets to shell anchors); Space-Fill = pinned level shells, radii auto-fit; Compare = one pinned ball per level. Size = degree.
UI language (top right)Node names follow the top-right interface language; every card lists ZH/EN/DE.
All / Math / Physics / ChemistryDiscipline switcher inside the viewer (?graph=steam fuses all three; ?graph=physics / ?graph=chemistry deep-links).
Click nodeDetail panel: trilingual labels, degree, role, HDS depth, finding link, Focus button.
Auto Rotate / WASDSlow orbit for presentations; WASD flies the camera (toggleable).
Legend colorsGreen elementary · teal middle · indigo high · purple college. Size = degree.
